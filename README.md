## 🔐 نظام الحماية وكلمة المرور (Admin Security Gate)

حرصاً على أمان موقعك ومنع أي زائر من التعديل أو العبث بالأعمال:
1. **قفل أمني تلقائي:**  
   عند النقر على `⚙️ لوحة التحكم` أو `✏️ تعديل` أو الزر العائم، تظهر أولاً نافذة **التحقق الأمني**.
2. **كلمة المرور الافتراضية:**  
   - يمكنك تسجيل الدخول باستخدام: `badr517` أو `admin123`.
3. **تغيير كلمة المرور:**  
   - بعد الدخول إلى لوحة التحكم، ستجد قسماً مخصصاً بعنوان `🔑 تغيير كلمة مرور لوحة التحكم`.
   - يمكنك إدخال كلمة المرور الحالية وتعيين كلمة مرور جديدة خاصة بك، وسيتم تشفيرها وتخزينها محلياً فوراً عبر تقنية تشفير الهاش الآمنة (SHA-256).
4. **تسجيل الخروج وقفل اللوحة:**  
   - في ترويسة لوحة التحكم، يتوفر زر `🚪 تسجيل الخروج` لقفل اللوحة فور انتهائك من التعديل.

## ⚙️ مميزات لوحة تحكم إدارة المحتوى

- **إضافة عمل جديد:** مع إمكانية رفع صورة من جهازك مباشرة وحفظها تلقائياً.

- **تحديث فوري (Live Update):** أي تغيير يُحفظ ويظهر فوراً في المعرض أمام الزوار.
- **استعادة الافتراضيات:** زر لإعادة المشاريع الأصلية بنقرة واحدة عند الحاجة.
